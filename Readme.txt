VERWIJDER HET ICOON NIET VAN JE BEGINSCHERM.
Op iOS heeft een app op het beginscherm een eigen opslag. Verwijder je
dat icoon, dan verdwijnen je seizoenen en wedstrijden mee.
Maak altijd eerst een back-up via het menu.


DE BESTANDEN
------------
Zet deze negen in de hoofdmap van je repository:

  index.html                vervangt de bestaande
  sw.js                     vervangt de bestaande
  manifest.webmanifest      vervangt de bestaande
  apple-touch-icon-v5.png   } de iconen uit versie 2.3.0
  icon-192-v5.png           } Heb je die al geupload, dan hoef
  icon-512-v5.png           } je ze niet opnieuw te doen.
  favicon-16-v5.png         }
  favicon-32-v5.png         }
  favicon-64-v5.png         }


VERSIE 2.4.0 — INSTALLEREN ALS APP
----------------------------------
In het menu staat nu "Installeer als app". Wat die knop doet hangt af
van het toestel:

  Android (Chrome, Edge)  -> opent het echte installatievenster van
                             het systeem. Eén tik en klaar.
  iPhone / iPad           -> toont de vier stappen met het deelicoon.
                             Apple laat een website niet toe dit zelf
                             te starten; dat is geen beperking van de
                             app maar van iOS.
  Computer                -> legt uit waar het installatie-icoon in
                             de adresbalk staat (Chrome en Edge).

De knop verdwijnt automatisch zodra de app al als app draait.

LET OP bij installeren vanuit Safari: de app op je beginscherm start
met een LEGE opslag. Wedstrijden die je in Safari hebt ingevoerd staan
daar niet in. Maak dus eerst een back-up in Safari en zet die terug
zodra de app vanaf het beginscherm geopend is.
